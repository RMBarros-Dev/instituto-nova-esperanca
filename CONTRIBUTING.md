# Como contribuo com o Instituto Nova Esperança

Mantenho este projeto como uma plataforma web/PWA de estudo, com conteúdo multilíngue, recursos de acessibilidade e scripts próprios de validação.

## Ambiente

Utilizo Node.js 22 para executar os scripts de desenvolvimento e qualidade.

## Verificações antes de enviar alterações

```bash
npm run qa
npm run test:i18n
npm run build
```

## Diretrizes

- Verifico as versões em português, inglês, espanhol, francês, alemão e japonês quando altero conteúdo multilíngue.
- Preservo a navegação por teclado, o contraste, os textos alternativos e as preferências de movimento reduzido.
- Não apresento certificações, parcerias, dados institucionais ou resultados sem fonte e autorização.
- Reviso os arquivos gerados antes de incluí-los na alteração.
- Não versiono credenciais nem dados pessoais.
