# Diretrizes de identidade visual — Instituto Nova Esperança

## Posicionamento

A identidade visual identifica o projeto de plataforma institucional multilíngue do repositório. Sua linguagem é acolhedora, sóbria e acessível, com ênfase em comunidade, informação, transparência e inclusão.

O nome e a identidade do projeto não comprovam, por si só, registro jurídico, vínculo com uma entidade real, autorização institucional ou validação de suas informações públicas.

## Conceito visual

O símbolo reúne duas formas verticais que representam pessoas e acolhimento. O arco central sugere encontro, apoio e continuidade; a linha de base funciona como horizonte comum. O desenho evita ícones genéricos de edifício, escudo ou mãos e mantém leitura simples em tamanhos reduzidos.

## Paleta oficial

A identidade externa acompanha os tokens centrais definidos em `assets/css/tokens.css` e no Design System.

| Token | HEX | Aplicação |
| --- | --- | --- |
| Verde institucional | `#0A5C46` | Estrutura, confiança e crescimento |
| Azul noturno | `#0D1B2A` | Fundos, títulos e contraste |
| Verde água | `#2A9D8F` | Conexões, destaques e elementos de interface |
| Âmbar | `#D97706` | Ênfase pontual e chamadas |
| Branco | `#FFFFFF` | Superfícies e leitura |
| Fundo claro | `#F8FAFC` | Contexto de aplicação clara |
| Texto | `#0F172A` | Texto principal |

## Ativos

- `assets/brand/logo.svg`: símbolo principal para fundos escuros.
- `assets/brand/logo-light.svg`: símbolo para fundos claros.
- `assets/brand/banner.svg`: banner horizontal para o README e apresentações.
- `assets/brand/project-mark.svg`: assinatura horizontal institucional.

## Regras de aplicação

- Preservar proporções, cores e área de respiro dos SVGs.
- Utilizar os ativos locais do repositório; não reconstruir o símbolo com emojis ou caracteres.
- Em fundos escuros, utilizar `logo.svg`; em fundos claros, utilizar `logo-light.svg`.
- Manter contraste, legibilidade e foco visível conforme o Design System.
- Não usar a marca para sugerir certificações, parcerias, resultados ou endosso institucional não comprovados.
- Não alterar os tokens de interface existentes apenas para adequar a marca.

## Assinatura

**Informação que aproxima. Ações que transformam.**

Esta assinatura é uma frase de posicionamento visual do projeto, não uma declaração factual de impacto social.
